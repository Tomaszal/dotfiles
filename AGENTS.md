# Agent Guide

## Operating Rules

- Determine the active machine with `hostname`.
- Machine names map directly to hostnames and `nixosConfigurations` names.
- Prefer shared aspects/defaults unless the user asks for a host-specific change.
- Prefer stable `pkgs` by default.
- Use `pkgs-unstable` only when stable does not provide the package or the user requests unstable.
- Do not edit `flake.nix` directly; it is generated by `flake-file`.
- Regenerate `flake.nix` with `nix run .#write-flake` only when changing `flake-file.*` inputs or parameters.
- Do not run `nix flake check` as the default validation step.
- Validate relevant system changes with `nh os build .` or an explicit host.
- Ask before editing `facter.json`, `disko.nix`, key-related files, or user identity configuration.

## Den Conventions

- Shared defaults usually belong under `den.default`.
- Reusable features usually belong under `den.aspects.<name>`.
- Host composition belongs in `modules/hosts/<host>/host.nix`.
- Host-specific system configuration can live in `den.aspects.<host>.nixos` or files imported by that host aspect.
- User-facing features should generally be included through `den.aspects.<host>.provides.to-users`.

## Important Paths

- `modules/flake/den.nix`: imports Den's dendritic flake module.
- `modules/flake/flake-file.nix`: generated flake settings.
- `modules/flake/dev-shell.nix`: development shell tools.
- `modules/nix/nixpkgs.nix`: stable and unstable nixpkgs inputs.
- `modules/nix/home-manager.nix`: Home Manager input and user schema class.
- `modules/nix/state-version.nix`: NixOS and Home Manager state versions.
- `modules/hosts/*/host.nix`: host definitions and aspect inclusion.
- `modules/hosts/*/disko.nix`: disk layouts. Ask before editing.
- `modules/hosts/*/facter.json`: hardware facts. Ask before editing.

## Editing Model

Prefer shared aspects unless a change is explicitly host-specific.

Use stable `pkgs` by default. Use `pkgs-unstable` only when a package is unavailable on stable or when the change specifically calls for it.

High-impact files should be edited deliberately and with clear intent:

- `modules/hosts/*/facter.json`
- `modules/hosts/*/disko.nix`
- key material or key references
- user identity configuration

## Validation Commands

Current host:

```
nh os build .
```

Specific host:

```
nh os build .#(pc|work|laptop)
```

Format Nix files:

```
nix fmt .
```
